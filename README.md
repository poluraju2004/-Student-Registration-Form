# HTML Practice – Student Registration Form

## Description
This is an HTML practice exercise to learn how to create a Student Registration Form using HTML form elements.

## Topics Practiced
- Headings and labels
- Text, email, password, and telephone inputs
- Date input
- Radio buttons
- Checkboxes
- Dropdown lists (`select` and `option`)
- Textarea
- Required fields and input validation
- Country calling code selection
- Submit and reset buttons
- Basic JavaScript input validation

## Technologies Used
- HTML5
- Basic JavaScript

## How to Run
1. Open the HTML file in Visual Studio Code.
2. Run it in a web browser.
3. Practice entering details and testing form validation.

## Purpose
To improve my understanding of HTML forms and practice using different input elements.

## Learning Status
HTML practice – Beginner level.
